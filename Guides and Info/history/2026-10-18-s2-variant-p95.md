# S2 variant P95 (2026-10-18)

Each API has two tables. The both-runs table is one row per variant. The second table is one row per run.

Holds: the unflagged folders in `experiments/results/final_runs_results/S2_sustained_overload_burst` and `S2_sustained_overload_normal`. Goodput on these holds: [2026-10-18-s2-variant-summary.md](2026-10-18-s2-variant-summary.md) and [2026-10-18-s2-api-summary.md](2026-10-18-s2-api-summary.md). Fail rate on these holds: [2026-10-18-s2-variant-fail-rate.md](2026-10-18-s2-variant-fail-rate.md). The same tables for S3: [2026-10-18-s3-variant-p95.md](2026-10-18-s3-variant-p95.md).

P95 is the Locust `Latency95` column, in ms. Mean P95 is the mean of that column on seconds with `RPS` > 0, the same seconds `analysis_score.locust_table` averages, so one run's mean matches that scorer's P95 for the API. Median P95 is the median of those same seconds. An even number of seconds uses the midpoint of the two central values.

The both-runs row gives each run equal weight. With two runs, median P95 is the midpoint of the two run medians.

No hold here has a throttle flag. `analysis_s2_both_normal_run1` is left out: health line **RL STALL** (two `RL_RPS_TIMEOUT` lines). The burst folder has no TopFull-only holds.
