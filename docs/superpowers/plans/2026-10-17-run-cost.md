# Run Cost Proxies Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `experiments/run_cost.py`, which turns an existing `final results/` hold into cost proxies (core-seconds, GB-seconds, inbound request-seconds, wasted CPU, cost per good request) and compares conditions as a percentage of a reference run, the way RetryGuard paper Table 1 reports "Resources Billing".

**Architecture:** One stdlib-only script of small pure functions over the CSVs a hold already contains (`resource_usage.csv`, `service_inbound.csv`, `service_edges.csv`, `total.csv`). Everything is integrated or differenced inside the hold window (first to last `total.csv` timestamp). A `main()` prints a per-run table, and with two or more run dirs also prints a per-scenario comparison normalized to `tf_only`.

**Tech Stack:** Python 3 stdlib (`csv`, `datetime`, `pathlib`), pytest. Reuses `analysis_score.locust_table` for goodput / fail / P95.

## Global Constraints

- No new VM runs. Only read existing folders under `experiments/results/final results/`.
- Do not use the frozen per-pod μ (`experiments/capacity/`). No required-replica or virtual-HPA model.
- Window is the Locust hold: first and last `timestamp` in `total.csv`. Folders without that column are rejected with a clear error (all `final results/` holds have it).
- App containers only. `resource_usage.csv` rows named `__master_node__` are excluded. `istio-proxy` CPU is not collected, so core-seconds are a lower bound on pod CPU.
- Cumulative Envoy counters are differenced between consecutive polls of the same key. Only positive deltas count (counter resets are dropped), matching `analysis_score.py`.
- Good requests = `Σ Goodput × Δt` using the Locust timestamp spacing (rows are about 1.05 s apart, not 1 s).
- Wasted CPU is an estimate: `cpu_per_request × wasted_requests`, cost per request assumed equal for all attempts. Report a range, never a single number.
- Report cost as a percentage of the reference run next to goodput, P95 and retries per request. Never cost alone (a controller that sheds everything looks cheap).
- No dollar rate card in code. A `$` figure is a single multiplication the reader can do.
- Do not read `topfull_throttle.csv`, so the throttle FLAG rule in AGENTS.md §6 does not apply.

```python
"""Cost proxies for one finished hold, from files the hold already has.

Core-seconds, GB-seconds, inbound request-seconds, wasted CPU, and cost per
good request, all inside the Locust hold window. See
docs/superpowers/plans/2026-10-17-run-cost.md for the definitions and limits.

    python experiments/run_cost.py "<run_dir>" ["<run_dir>" ...]
"""

from __future__ import annotations

import csv
import sys
from collections import defaultdict
from datetime import datetime
from pathlib import Path

SERVICES = (
    "frontend", "cartservice", "checkoutservice", "productcatalogservice",
    "paymentservice", "recommendationservice", "shippingservice",
    "currencyservice", "emailservice", "adservice", "redis-cart",
)
READ_CALLEES = ("adservice", "currencyservice", "productcatalogservice", "recommendationservice")


def parse_ts(value: str) -> float:
    return datetime.fromisoformat(value.replace("Z", "+00:00")).timestamp()


def read_rows(path: Path) -> list[dict]:
    with open(path, newline="") as f:
        return list(csv.DictReader(f))


def hold_window(run_dir: Path) -> tuple[float, float]:
    rows = read_rows(run_dir / "total.csv")
    if not rows or "timestamp" not in rows[0]:
        raise ValueError(f"{run_dir}: total.csv has no timestamp column")
    stamps = [parse_ts(r["timestamp"]) for r in rows]
    return min(stamps), max(stamps)


def integrate(rows: list[dict], window: tuple[float, float], column: str) -> dict[str, float]:
    """Left-rectangle integral of `column` per service over the window."""
    start, end = window
    by: dict[str, list[tuple[float, float]]] = defaultdict(list)
    for r in rows:
        if r["service"] in SERVICES:
            by[r["service"]].append((parse_ts(r["timestamp"]), float(r[column])))
    out: dict[str, float] = {}
    for svc, pts in by.items():
        pts.sort()
        total = 0.0
        for (t0, v0), (t1, _) in zip(pts, pts[1:]):
            lo, hi = max(t0, start), min(t1, end)
            if hi > lo:
                total += v0 * (hi - lo)
        out[svc] = total
    return out


def deltas(rows: list[dict], key_fn, columns: tuple[str, ...], window: tuple[float, float]) -> dict:
    """Sum of positive deltas between consecutive polls of one key, later poll in (start, end]."""
    start, end = window
    by = defaultdict(list)
    for r in rows:
        by[key_fn(r)].append(r)
    out: dict = {}
    for key, grp in by.items():
        grp.sort(key=lambda r: r["timestamp"])
        acc = dict.fromkeys(columns, 0.0)
        for prev, cur in zip(grp, grp[1:]):
            if not (start < parse_ts(cur["timestamp"]) <= end):
                continue
            for c in columns:
                d = float(cur[c]) - float(prev[c])
                if d > 0:
                    acc[c] += d
        out[key] = acc
    return out
```

Waste definitions (per service, hold totals): `R` = Σ `Δretry` over edges whose target is the service. `F` = `Δ5xx + Δresets`, plus `Δgrpc_4 + Δgrpc_14` on `READ_CALLEES`. `N` = `Δtotal`. A retry that fails is in both R and F, so the union is between `max(R, F)` and `min(R + F, N)`. `low` and `high` use those bounds.

```python
INBOUND_COLUMNS = ("total", "5xx", "resets", "grpc_4", "grpc_14", "rq_time_sum_ms")


def waste(core_s: dict[str, float], inbound: dict, edges: dict) -> dict[str, dict]:
    retries_to: dict[str, float] = defaultdict(float)
    for (_caller, target), d in edges.items():
        retries_to[target] += d["retry"]
    out: dict[str, dict] = {}
    for svc, cs in core_s.items():
        inb = inbound.get(svc)
        n = inb["total"] if inb else 0.0
        if n <= 0:
            continue
        per_req = cs / n
        r = retries_to.get(svc, 0.0)
        f = inb["5xx"] + inb["resets"]
        if svc in READ_CALLEES:
            f += inb["grpc_4"] + inb["grpc_14"]
        out[svc] = {
            "core_s": cs,
            "per_req": per_req,
            "retry": per_req * r,
            "failed": per_req * f,
            "low": per_req * min(max(r, f), n),
            "high": per_req * min(r + f, n),
        }
    return out


def good_requests(rows: list[dict]) -> float:
    pts = sorted((parse_ts(r["timestamp"]), float(r["Goodput"])) for r in rows)
    return sum(g * (t1 - t0) for (t0, _), (t1, g) in zip(pts, pts[1:]))


def cost_run(run_dir: Path) -> dict:
    window = hold_window(run_dir)
    usage = read_rows(run_dir / "resource_usage.csv")
    core_by = {s: v / 1000.0 for s, v in integrate(usage, window, "cpu_millicores").items()}
    gb = sum(integrate(usage, window, "memory_working_set_bytes").values()) / 1e9
    inbound = deltas(read_rows(run_dir / "service_inbound.csv"), lambda r: r["service"], INBOUND_COLUMNS, window)
    edges = deltas(read_rows(run_dir / "service_edges.csv"), lambda r: (r["caller"], r["target"]), ("total", "retry"), window)
    w = waste(core_by, inbound, edges)
    total_rows = read_rows(run_dir / "total.csv")
    good = good_requests(total_rows)
    core_total = sum(core_by.values())
    first_attempts = sum(d["total"] - d["retry"] for d in edges.values())
    retries = sum(d["retry"] for d in edges.values())
    live = [r for r in total_rows if float(r["RPS"]) > 0]
    n = len(live) or 1
    return {
        "run": run_dir.name,
        "scenario_mode": run_dir.parent.parent.name,
        "variant": run_dir.parent.name,
        "core_s": core_total,
        "core_s_by_service": core_by,
        "gb_s": gb,
        "request_s": sum(d["rq_time_sum_ms"] for d in inbound.values()) / 1000.0,
        "waste": w,
        "waste_retry": sum(x["retry"] for x in w.values()),
        "waste_failed": sum(x["failed"] for x in w.values()),
        "waste_low": sum(x["low"] for x in w.values()),
        "waste_high": sum(x["high"] for x in w.values()),
        "good": good,
        "core_ms_per_good": (core_total * 1000.0 / good) if good > 0 else None,
        "goodput": sum(float(r["Goodput"]) for r in live) / n,
        "fail": sum(float(r["Fail"]) / float(r["RPS"]) for r in live) / n,
        "p95": sum(float(r["Latency95"]) for r in live) / n,
        "rpr": (retries / first_attempts) if first_attempts > 0 else None,
    }
```

Note: `goodput`, `fail`, and `p95` use the same definitions as `analysis_score.locust_table` (mean over rows with `RPS > 0`). They are recomputed here so the module stays stdlib-only and testable without importing `analysis_score`. If the two ever disagree, `analysis_score` wins.

```python
def _split(scenario_mode: str) -> tuple[str, str]:
    scenario, _, mode = scenario_mode.rpartition("_")
    return scenario, mode


def _f(value, spec: str) -> str:
    return "-" if value is None else format(value, spec)


def render_run(c: dict) -> str:
    lines = [
        f"### {c['scenario_mode']} / {c['variant']} / {c['run']}",
        "",
        f"- Core-seconds (app containers, 11 services): **{c['core_s']:.1f}**",
        f"- Memory GB-seconds: {c['gb_s']:.1f}",
        f"- Inbound request-seconds (sum of `rq_time_sum_ms`): {c['request_s']:.1f}",
        f"- Good requests: {c['good']:.0f}. Core-ms per good request: {_f(c['core_ms_per_good'], '.2f')}",
        f"- Wasted CPU, core-seconds: retry-only {c['waste_retry']:.2f}, failed-attempts {c['waste_failed']:.2f}, "
        f"union range {c['waste_low']:.2f} to {c['waste_high']:.2f}",
        f"- Goodput {c['goodput']:.1f} req/s, P95 {c['p95']:.0f} ms, Fail/RPS {c['fail']:.3f}, retries per first attempt {_f(c['rpr'], '.3f')}",
        "",
        "| Service | Core-s | CPU per request (core-ms) | Wasted low | Wasted high |",
        "|---|---|---|---|---|",
    ]
    for svc in SERVICES:
        if svc not in c["core_s_by_service"]:
            continue
        w = c["waste"].get(svc)
        lines.append(
            f"| {svc} | {c['core_s_by_service'][svc]:.1f} | "
            f"{_f(w['per_req'] * 1000 if w else None, '.3f')} | "
            f"{_f(w['low'] if w else None, '.2f')} | {_f(w['high'] if w else None, '.2f')} |"
        )
    return "\n".join(lines)


def _mean(values: list[float]) -> float:
    return sum(values) / len(values)


def _mean_opt(values: list) -> float | None:
    kept = [v for v in values if v is not None]
    return _mean(kept) if kept else None


def render_compare(costs: list[dict]) -> str:
    by_scenario: dict[str, dict[tuple[str, str], list[dict]]] = defaultdict(lambda: defaultdict(list))
    for c in costs:
        scenario, mode = _split(c["scenario_mode"])
        by_scenario[scenario][(mode, c["variant"])].append(c)
    blocks = []
    for scenario, groups in sorted(by_scenario.items()):
        ref_key = ("normal", "tf_only") if ("normal", "tf_only") in groups else next(iter(groups))
        ref = groups[ref_key]
        ref_core = _mean([c["core_s"] for c in ref])
        ref_req = _mean([c["request_s"] for c in ref])
        note = "tf_only (normal)" if ref_key == ("normal", "tf_only") else f"{ref_key[1]} ({ref_key[0]}), no tf_only found"
        lines = [
            f"### {scenario}",
            "",
            f"Reference (100%): {note}, {len(ref)} run(s), mean {ref_core:.1f} core-s.",
            "",
            "| Mode | Variant | Runs | Core-s | % of ref | % range | Request-s % of ref | "
            "Wasted core-s (low to high) | Core-ms per good | Goodput | P95 ms | Fail/RPS | rpr |",
            "|---|---|---|---|---|---|---|---|---|---|---|---|---|",
        ]
        for (mode, variant), runs in sorted(groups.items()):
            core = [c["core_s"] for c in runs]
            lines.append(
                f"| {mode} | {variant} | {len(runs)} | {_mean(core):.1f} | {100 * _mean(core) / ref_core:.0f}% | "
                f"{100 * min(core) / ref_core:.0f}-{100 * max(core) / ref_core:.0f}% | "
                f"{100 * _mean([c['request_s'] for c in runs]) / ref_req:.0f}% | "
                f"{_mean([c['waste_low'] for c in runs]):.1f} to {_mean([c['waste_high'] for c in runs]):.1f} | "
                f"{_f(_mean_opt([c['core_ms_per_good'] for c in runs]), '.2f')} | "
                f"{_mean([c['goodput'] for c in runs]):.1f} | {_mean([c['p95'] for c in runs]):.0f} | "
                f"{_mean([c['fail'] for c in runs]):.3f} | "
                f"{_f(_mean_opt([c['rpr'] for c in runs]), '.3f')} |"
            )
        blocks.append("\n".join(lines))
    return "\n\n".join(blocks)


def main(argv: list[str]) -> int:
    dirs = [Path(a) for a in argv if not a.startswith("--")]
    if not dirs:
        print('usage: python experiments/run_cost.py "<run_dir>" ["<run_dir>" ...]')
        return 2
    costs = [cost_run(d) for d in dirs]
    for c in costs:
        print(render_run(c))
        print()
    print(render_compare(costs))
    return 0


if __name__ == "__main__":
    raise SystemExit(main(sys.argv[1:]))
```

**Placeholder scan:** none. Every code step has full code and exact commands.

**Type consistency:** `deltas` returns key → column → float, and `waste` reads `inbound[svc]["total" | "5xx" | "resets" | "grpc_4" | "grpc_14"]` and `edges[(caller, target)]["retry"]`. `cost_run` requests exactly those columns (`INBOUND_COLUMNS`, `("total", "retry")`). `render_compare` reads only keys `cost_run` produces.

**Known limits (state them in the write-up, not in code):**
- Sidecar CPU is excluded, so core-seconds understate pod cost, and retries cost Envoy CPU too.
- CPU saturates at limits in overload, so core-seconds measure used capacity, not demand.
- `waste` assumes equal CPU per attempt. Failed attempts are probably cheaper, so the high bound can overstate.
- The `% range` column is min–max across runs. With 2 runs per cell it is not a confidence interval.
